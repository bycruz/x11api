# x11api [![Tests](https://github.com/bycruz/x11api/actions/workflows/tests.yml/badge.svg)](https://github.com/bycruz/x11api/actions/workflows/tests.yml)

X11 bindings for LuaJIT.

## Installation

Set up [lde](https://github.com/lde-org/lde).

```bash
lde add --git https://github.com/bycruz/x11api
```
